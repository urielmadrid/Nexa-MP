# Nexa MP

Landing page institucional da Nexa MP, construída com Next.js, React, TypeScript e Tailwind CSS.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
npm run start
```

Defina `NEXT_PUBLIC_SITE_URL` com a URL canônica do domínio publicado. Essa variável é usada pelo metadata, `robots.txt` e sitemap.

## Estrutura

- `app/` — App Router, metadata, sitemap, robots e manifest.
- `src/components/` — layout, seções e componentes reutilizáveis.
- `src/lib/data/` — conteúdo estruturado do site.
- `public/` — assets públicos e `llms.txt`.

O portfólio público não usa projetos fictícios. Cases devem ser adicionados somente quando houver dados reais aprovados para publicação.
